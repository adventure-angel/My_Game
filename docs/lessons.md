# 星糖物语：第一款游戏的制作经验

这份复盘依据原工程的阶段文档、当前源码与已有测试记录整理。它记录做过的选择和发现的问题，不把历史方案当成当前规则，也不把构建成功当成线上验收。

## 1. 先打通短体验，再扩数量

最初的三消原型只有棋盘与界面。后来把“序章认识月见 → 通过前三关 → 得到夜灯 → 回小屋亲手点亮”串成一段闭环，玩家才有继续消除的具体理由。关卡从 36 扩到 72 后，中段机制仍需重新审视；关卡数增加不自动等于节奏完整。

## 2. 消消乐要让玩家有选择

棋盘只保证“至少一步可走”还不够。工程后来对生成棋盘评估合法交换数量和分布，尽量让不同区域都有行动选择；无解时允许免费重排。元素反应和特殊糖叠加后，预览、真正结算、计分与反馈要使用同一套确定顺序，否则玩家看不懂结果。

## 3. 视觉一致性比单张漂亮更重要

角色月见曾在封面、头像和立绘中出现不同面孔，后来以封面为身份母版逐用途核对。金币、钻石等图标也要放进实际手机大厅看小尺寸识别，而非只看原图。小屋必须同时检查空房与满布置，装饰不能遮住角色或操作区。

## 4. 手机首屏和退出路径要实际检查

准备页、签到、商店与漫画在桌面上能看，不代表手机上好用。较长内容要能独立滚动，关闭按钮保持可见；漫画需按素材比例和最终容器裁切。战斗界面优先让目标、分数、棋盘、道具和结果反馈都在可操作范围内。

## 5. 经济规则改变要迁移整条状态链

本作经历了充值与体力方案、广告经济、取消体力等变化。删除一个按钮并不够：开局扣除、恢复、旧档、文案、奖励来源和商品权益都要同步。道具“携带”与“使用”是两件事，普通关后来改为实际使用才扣库存，并在保存失败时回滚。

## 6. 存档、平台和宣发都要按证据说话

本地存档、云备份、榜单回执、广告播放、审核、线上主包与公开页游玩属于不同状态。旧二维码或旧包可能仍展示旧规则，源码更新不证明玩家已经玩到新版本。宣传片、店铺图和截图也有版本：镜头里出现的内容需要和游戏实际版本对得上，画面连续还要检查叙事顺序。
