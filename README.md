# 星糖物语 Star Candy

一款手机优先的 H5 消消乐游戏。玩家交换 7×7 棋盘中的星糖，使用伙伴技能与元素反应通关，每三关取得一件收藏，逐步点亮小屋。当前源码配置为 **v47 / 72 关**。

> 这是第一款游戏的工程整理。它包含可复用的三消规则，也包含星糖物语自己的剧情、美术、经济与 TapTap 接入。请先看 [复用指南](docs/reuse.md) 和 [素材说明](docs/assets-and-rights.md)。

## 从哪里开始

- **想试玩**：打开 [`playable/v47/index.html`](playable/v47/index.html)。该目录是已有的 v47 静态 H5 包；网页直接打开和在平台容器中打开，平台功能可能不同。建议用本地静态服务器提供该目录。
- **想借用三消机制**：看 [`src/engine.js`](src/engine.js)（棋盘、交换、匹配、掉落）与 [`src/elements.js`](src/elements.js)（元素反应），再看 [复用指南](docs/reuse.md)。
- **想研究完整游戏**：看 [分层说明](docs/architecture.md)、`src/`、`scripts/` 和 `config/release.json`。
- **想看制作过程**：看 [经验复盘](docs/lessons.md) 与 `docs/history/` 中保留的阶段记录。
- **想看宣传资料**：见 [宣传素材目录](media/README.md)。

## 本仓库结构

| 目录 | 内容 | 复用时需要注意 |
| --- | --- | --- |
| `src/engine.js`、`src/elements.js` | 三消棋盘与元素反应核心 | 规则仍有项目特定数值，需按新游戏调整 |
| `src/` 其余文件 | 关卡、伙伴、存档、经济、小屋、界面与平台适配 | 多数依赖现有全局状态和 DOM，不能单文件复制即运行 |
| `assets/` | 当前构建使用的压缩美术与两首循环音乐 | 素材授权证据与代码授权分开 |
| `scripts/`、`config/`、`index.html` | 原工程构建入口、配置与 HTML 模板 | 构建脚本有历史版本链，详见分层说明 |
| `playable/v47/` | 可供本地查看的静态包 | 是打包产物，不是可复用源码的入口 |
| `media/` | 宣传片、方图、横幅与代表性截图 | 截图与成片对应不同制作阶段，见目录说明 |
| `docs/` | 复用、经验、素材来源和少量阶段记录 | 历史记录不代表当前线上状态 |

## 本地构建

需要 Node.js。此工程不依赖 npm 安装包。进入仓库根目录运行：

```sh
node scripts/package-mirror-ads.cjs
```

构建会更新根目录的 `index.html`、生成 `mobile-play.html` 和 `release/h5-mirror-ads-v47/`。本仓库整理时已从当前源码成功重新构建一次；这只验证构建过程，不代表所有设备、72 关平衡或 TapTap 服务均已验收。`config/release.json` 含原项目的公开应用配置；移植时应替换平台标识并检查广告、榜单和云存档路径。
