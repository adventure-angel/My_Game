# 宣传素材

- `trailer/star-candy-trailer-github-720p.mp4`：可直接观看的压缩版宣传片。
- `trailer/original-1080p.parts/`：既有 1080p 成片的原字节分片。运行仓库根目录的 `python scripts/restore-large-files.py trailer` 可还原原文件并校验 SHA-256。名称中的 `final` 是原文件名，不代表与本仓库 v47 包完全同步。
- `promo/square.jpg`、`promo/banner.jpg`：无小字版方图和横幅，可用于展示游戏形象。
- `screenshots/`：v45 挑战分数、v46 小屋与猫动作的代表性截图。文件名保留阶段信息，便于判断画面对应的版本。

这些媒体用于展示星糖物语的制作过程和视觉效果。素材权利状态见 [`docs/assets-and-rights.md`](../docs/assets-and-rights.md)。请勿将历史截图作为当前平台运行证据。
